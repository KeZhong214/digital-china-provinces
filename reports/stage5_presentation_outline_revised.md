# 第五阶段课堂汇报大纲（修订版，11 页）

> 用途：直接指导 PPT 制作。每页给出**页面标题 / 中心句 / 放什么图 / 口头讲什么 / PPT 上只写什么**。
> 课程背景：思想政治理论课（硕士1）实践教学·课堂汇报，主题“中国式现代化”。建议时长 12–14 分钟（11 页）。
> 研究定位：**基于公开数据的31省数字化发展分项画像研究**；不呈现任何综合排名。

## 一、总原则

1. **一页一个结论**：每页中心句就是该页 PPT 标题，页面上不再出现第二个结论。
2. **上屏不超过 25 字**（不含图表内文字与图注）；推理过程、口径解释、举例全部放口播。
3. **每页只放一张图**：主图独占页面 60% 以上面积，文字退到边栏或底部。
4. **每次说“差异”，紧跟一句“不等于落后”**（东北档级一页除外，见 P8）。
5. **收尾必须回到“区域协调发展”**：差异是结构，协调是接口。

## 三、逐页文案

### P1　数字中国的省际图景

- **中心句**：31省数字化发展分项画像——不做总榜，也能讲清区域差异。
- **上屏**：主标题 + 副标题（“31省 · 2024 · 分项画像”）；汇报人/课程/日期。
- **放什么图**：无；可用图A 的缩略图做背景（低透明度）。
- **口头讲什么**：一句话点题——“我们原本想做排行榜，做完数据后决定不排；今天讲为什么，以及不排名还能讲清什么。”
- **只写什么**：标题、副标题、署名。

### P2　为什么看省际差异

- **中心句**：数字中国如果只报全国平均，就回答不了“谁被平均掉了”。
- **上屏**（三行，每行≤12字）：
  1. 数字化既是动能，也可能是差距放大器
  2. 省是政策责任与数据的最小共同单元
  3. 区域协调关心差距落在哪里
- **放什么图**：无（保持干净）。
- **口头讲什么**：用“同一条宽带，中心与边缘收益不同”解释数字鸿沟的双面性；强调本研究只做描述、不评价政策。
- **只写什么**：三行短句。

### P3　三个指标，一个决定：不做总榜

- **中心句**：能测三项，但只做分项展示，不合成总分。
- **上屏**（三行小表）：

| 维度 | 测到什么 | 不测什么 |
|---|---|---|
| D1 企业数字交易应用 | 电商参与比例（2024全年） | 交易额、产业增加值 |
| D2 固定宽带接入配置 | 每百人账户数（2024年末） | 网速、覆盖、体验 |
| D3 网上政府档级 | 优秀/良好/中等（9—10月） | 精确分数、档内次序 |

- **放什么图**：小表即为“图”。
- **口头讲什么**：三个理由（代理效度、权重无依据、D3 时间归属未确认）；强调“不排名”是研究结论的一部分。
- **只写什么**：表格 + 一句“不合成总分”。

### P4　企业数字交易应用：北京最高，东部并非整体高位

- **中心句**：前五有重庆，后五有天津、河北。
- **上屏**：地图 + 一句“北京23.29%，天津第27、河北第28”。
- **放什么图**：图A（`map_ecommerce_2024_combo.png`）。
- **口头讲什么**：
  - 先教读图：颜色越深越高，右侧是前五/后五与名次。
  - 点三个位置：北京第1、重庆第3、河北第28。
  - 补一句中段：第10到第22位只差1.64个百分点，名次被放大了。
- **只写什么**：中心句 + 图 + 页脚口径小字（“调查企业电商参与比例，不是数字经济规模”）。

### P5　固定宽带接入配置：海南最高，广东最低

- **中心句**：广东最后一名，但这张图测的是配置，不是设施强弱。
- **上屏**：地图 + 一句“广东39.51（第31），千兆占比29.78%”。
- **放什么图**：图B（`map_accounts_2024_combo.png`）。
- **口头讲什么**：
  - 分布：均值48.23、极差18.63、CV 10.66%，比 D1 集中。
  - 西部有高位：宁夏第5、青海第7、新疆第10。
  - 广东：账户密度最低，但同年末千兆以上占29.78%；账户密度受家庭规模、机构账户、固定/移动替代影响，本项目无31省拆分数据，不能确定原因。
- **只写什么**：中心句 + 图 + 页脚（“只测接入配置，不测网速与覆盖”）。

### P6　区域差异：均值最高，不代表内部最均衡

- **中心句**：东部均值最高，内部差距也最大；中西部接近，次序取决于口径。
- **上屏**：图 + 两句：
  - “东部D1极差14.75＝北京与河北之差”
  - “西部均值11.80＞中部11.36；中位数12.23＞11.40”
- **放什么图**：图C（`regional_mean_median_comparison.png`）。
- **口头讲什么**：
  - 教读图：圆点均值、菱形中位数、右侧名次。
  - 东部：均值最高但极差最大；东北最均衡却是低位均衡（CV 3.84%、均值8.13）。
  - 中西部：均值西部高、中位数中部高；删重庆后西部11.32，反转。
  - 落到表述：“接近、排序不稳健，不说谁更高。”
- **只写什么**：两句结论 + 图。

### P7　两个维度，几乎不重合

- **中心句**：如果两个指标测的是同一件事，这些点应该沿一条斜线排开；它们没有。
- **上屏**：图 + 一句“r=0.18/0.27，平均名次差9.2位”。
- **放什么图**：图D（`scatter_ecommerce_accounts_quadrant.png`）。
- **口头讲什么**：
  - 指三组点：北京（左上）、广东（左下）、宁夏（右下）。
  - 京冀：两个点几乎垂直对齐——配置差0.10，应用差14.75。
  - 强调：低相关不等于“基础设施没用”，只说明省级横截面不能互相预测。
- **只写什么**：中心句 + 图 + “描述性，不做因果”。

### P8　网上政府档级：不是一条从东到西的直线

- **中心句**：西部优秀率41.7%，高于中部16.7%；东北没有优秀档。
- **上屏**：图 + 一句“东部70.0%｜西部41.7%｜中部16.7%｜东北0%”。
- **放什么图**：图E（`gov_category_distribution.png`）。
- **口头讲什么**：
  - 结构：优秀13、良好14、中等4。
  - 反差：西部5个优秀（内蒙古、重庆、四川、贵州、云南），中部只有1个（安徽）。
  - 边界：档级是分类，不转分数、不比档内次序；东北仅3省，比例解读要谨慎。
- **只写什么**：中心句 + 图 + “档级为分类，不转分数”。

### P9　北京—河北：差在应用，不在配置

- **中心句**：两省接入配置只差0.10户/百人，企业应用却差14.75个百分点。
- **上屏**：图 + 一句“同属东部，同一种配置，两种应用水平”。
- **放什么图**：图F1（`case_card_beijing_hebei.png`）。
- **口头讲什么**：
  - 数据：北京23.29/45.45，河北8.53/45.35。
  - 实践：北京417项一网通办、三地自贸区230项同事同标；河北1053项跨省通办、社保卡5个场景。
  - 含义：协调的抓手是标准互认与跨域受理，不是把指标拉平。
  - 边界：事项数≠办理量；417与1053口径不同，不能相加。
- **只写什么**：中心句 + 图。

### P10　宁夏：西部的另一种路径

- **中心句**：配置第5、应用第21，同时有中卫算力项目与算电协同部署。
- **上屏**：图 + 一句“不同地区不必在同一条应用赛道上同序竞争”。
- **放什么图**：图F2（`case_card_ningxia.png`）。
- **口头讲什么**：
  - 数据：D1 11.03%（第21）、D2 53.14（第5）。
  - 事实：中卫7个项目投运、标准机架12.1万架；2024年国家数据局在宁夏等枢纽部署算电协同。
  - 边界：中卫≠全宁夏，机架≠利用率，项目存在≠指标提升。
  - 若时间允许，一句话带过广东（图F3）：账户密度最低≠设施最弱。
- **只写什么**：中心句 + 图。

### P11　结论与启示：协调不是同序，而是互补

- **中心句**：差异是结构性的，协调的抓手在接口。
- **上屏**（三条，每条≤20字）：
  1. 省际差异显著，但形态不同
  2. 区域差异也在区域内部，次序依赖口径
  3. 维度不同步：协调重在优势互补
- **放什么图**：无（文字页）；可在右下角放三张主图缩略图。
- **口头讲什么**：每条配一个数字（15.60 / 14.75 / r=0.18）；最后一句讲局限——代理指标、无综合榜、未测普惠与体验。
- **只写什么**：三条结论 + 一行“局限：代理指标／无综合榜／未测普惠”。

## 五、口播提示卡

1. **开场 20 秒**：“我们原本想做一张31省的数字现代化排行榜；做完数据之后，我们决定不排——今天讲的就是为什么，以及不排名还能讲清什么。”
2. **每张图第一句**先说“这张图看什么”，再说“看到什么”，最后说“所以呢”。
3. **遇到数字先给口径**：“这个数测的是账户配置，不是网速。”
4. **每次说“差异”紧跟“不等于落后”**（P8 档级除外）。
5. **收尾 20 秒**：“31省的数字图景不是一个梯度，而是一组不同步的位置；区域协调要做的，是让这些位置之间的接口接得上。”
