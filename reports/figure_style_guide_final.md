## 2. 地图专项规范（本阶段新增）

### 2.1 台湾省显示要求

1. 地图**必须包含中国台湾省**，几何形状完整，不得裁切、不得留白，**不得被任何附图、图例或表格遮挡**。
2. 台湾省填色采用"未纳入样本"灰（见 2.3），但**必须双行标注**：第一行"中国台湾省"（7.2–7.4pt、墨色、白色描边），第二行"（未纳入样本）"（6.0pt、MUTED）；标注置于岛屿正上方偏东，用 0.6pt 细引线指向岛屿。
3. 图注必须写明："地图中保留中国台湾省及相关版图要素，仅用于完整展示中国版图。"
4. 台湾省不参与分级着色、不编号、不进入任何统计。

### 2.2 港澳处理方式

1. 香港、澳门在底图中正常显示（几何保留），填色同"未纳入样本"灰。
2. 因面积过小，**不在图上单独标注**，统一由图例与图注说明"灰色：港澳台（未纳入统计样本）"。
3. 港澳不编号、不进入对照表、不参与任何统计。

### 2.3 未纳入样本地区的颜色

| 类别 | 色值 | 说明 |
|---|---|---|
| 未纳入样本（台湾、香港、澳门） | `#E9E7E1` 暖灰 | 与五级色阶明显区分，明度高于最低级 |
| 研究省份最低级 | `#DCE6E4` 浅青灰 | 与暖灰有色相差异，避免混淆 |

### 2.4 编号规则

1. 31个研究省份统一编号 **01—31**，采用两位数字（`01`、`09`、`31`）。
2. 编号顺序：**按区域分组，组内按行政代码**——东部 01—10、中部 11—16、西部 17—28、东北 29—31。
3. 编号**不代表名次**，副标题必须写明"编号仅作标识，按区域分组排列，不代表名次"。
4. 编号圆点：直径约 9pt，白底 + 深灰描边 0.7pt，数字 5.9pt；**关键省份（北京、河北、广东、宁夏、重庆）用陶红底 + 白字**。
5. 小面积省份（北京、天津、上海、宁夏、重庆、海南等）允许圆点外移，并用 0.5pt 细引线连回省域。

### 2.5 右侧省份对照表样式

1. 位置：地图右侧，宽约 4.7 in，与地图顶部对齐。
2. 字段：**编号 ｜ 省份 ｜ 区域 ｜ 数值 ｜ 档级**（数值列右对齐，其余左对齐）。
3. 行高 0.146 in，字号 6.8–7.4pt；区域切换处加一条 `GRID` 细线分隔。
4. 关键省份整行用陶红加粗；表头上方加一行摘要："最高 X ｜ 最低 Y ｜ 极差 Z"。
5. 表下两行小字：关键省份说明、编号规则说明。
6. 表不带外框、不加底色，仅用细线分隔。

### 2.6 地图配色规则

| 级别 | 色值 |
|---|---|
| 第5级（最高） | `#2E6373` |
| 第4级 | `#5A8789` |
| 第3级 | `#8DAFAC` |
| 第2级 | `#B9CFCB` |
| 第1级（最低） | `#DCE6E4` |

- 单色顺序色阶，浅→深对应低→高；两张地图共用同一色阶，同一颜色在两图中含义相同。
- 分级为31省排序的**五等分中点断点**（D1 8.93/11.35/12.28/13.20；D2 42.98/45.57/50.38/52.00）。
- 省界白色 0.55pt；九段线 `#6E6A63` 0.85pt；南海诸岛小图底 `#FBFBFA`。
- **南海诸岛小图固定置于地图西南角空白海面**（约 0.92×1.10 in，带细边框），**严禁覆盖台湾岛及其标注**；九段线在主图中只保留台湾以东的北段，完整线型由小图承载。
- **图例横排五级置于图框下方**（不做地图内嵌），右侧同一行写"灰色：港澳台（未纳入统计样本）"；图例与页脚之间保留 ≥0.15 in 空隙。

### 2.7 关键省份高亮规则

- 固定五个：**北京、河北（D1 的最高与东部最低）、广东（D2 最低）、宁夏（D2 西部最高）、重庆（D1 第3、区域均值影响点）**。
- 高亮方式：编号圆点陶红底白字 + 对照表整行陶红加粗；两者必须同时出现。
- 不在图上加数值气泡（数值由右侧对照表承载），避免地图过载。

### 2.8 地图适配 PPT 的尺寸建议

| 版本 | 画布 | 适用 |
|---|---|---|
| 编号地图 + 信息面板（终版） | 13.333×7.5 in（3999×2250） | PPT 主图，建议整页铺满 |
| 纯地图版（stage5 输出） | 10.6×8.4 in | 印刷稿、全屏展示、备用页 |

- 插入 PPT 时使用 PDF 或 300dpi PNG；缩放不超过 150%。
- 投影偏色时优先保证五级色阶的明度差，不改成高饱和色。

### 2.9 双版本输出要求

- **必出**：`map_d1_ecommerce_final`、`map_d2_accounts_final`（编号地图 + 信息面板，用于 PPT 主图）。
- **保留**：stage5 的 `map_ecommerce_2024`、`map_accounts_2024`（纯地图版），用于印刷稿或需要"只看空间格局"的场合。
- 两版使用同一分级、同一色阶、同一底图，只在标签方式与版面组织上不同。

## 5. 数值标签与小数规则

1. 图内数值：D1/D2 对照表与标签保留 2 位（23.29、48.23）；档级占比保留 1 位（70.0%）。
2. 名次写"第 X / 31"或"X/31"；名次差在注释中说明正负方向。
3. 底表保留 4 位小数，正文引用 2 位；同一数字在不同载体上不得出现不同取整规则。
4. 不使用"领先/滞后/达标/警戒"等评价词。

## 6. 图注模板（六要素，终版）

```
数据：<表名/来源编号>；统计期<年/月/窗口>。
指标定义：<公式或口径>；<不能读成什么>。
说明：本研究统计对象为中国内地31个省级行政区；港澳台未纳入样本统计。地图中保留中国台湾省及相关版图要素，仅用于完整展示中国版图。（仅地图）
底图：<来源>，仅作示意。（仅地图）
分级/排序：<五分位断点或排序方式>；底表 <相对路径>。
```

**示例（主图1）**：
> 数据：国家统计局《中国统计年鉴2025》表16-39（E02）；统计期2024年全年。
> 指标定义：有电子商务交易活动企业数 ÷ 同表调查企业数 × 100；调查范围为规模以上工业等一套表企业，不是全部企业或居民。
> 说明：本研究统计对象为中国内地31个省级行政区；港澳台未纳入样本统计。地图中保留中国台湾省及相关版图要素，仅用于完整展示中国版图。
> 底图为阿里云 DataV 省级边界，仅作示意。

## 8. PPT 适配建议

1. 主图整页铺满，标题与页脚口径单独排版（不要把标题压在图上）。
2. 地图类主图（主图1、2）投影时若后排看不清编号，用激光笔配合右侧对照表讲解，不改字号。
3. 矩阵图（主图5）与旭日图（主图6）适合半页 + 半页文字的版式；散点与区域图适合整页。
4. 案例卡（主图7）一卡一页；京冀卡可整页，宁夏/广东卡可半页 + 一句口播要点。
5. 动画只用"出现/淡入"；地图可分两步（先省界后着色），旭日可分两步（先内环后外环）。
