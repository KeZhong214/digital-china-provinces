## 二、主图详情

### 图A　企业数字交易应用（地图组合版）

- **文件**：`map_ecommerce_2024_combo.png` / `.pdf`（16:9，3999×2250）
- **回答**：31省 D1 的空间格局；高值、低值与关键省份。
- **数据**：`map_panel_d1.csv`、`map_classes_d1.csv`；国家统计局《中国统计年鉴2025》表16-39（E02），2024年全年。
- **图形要素**：中国省级地图五分位着色 + 南海诸岛小图 + 右侧前五/后五（含名次）+ 竖排图例 + 北京/河北数值标注 + 三行图注。
- **核心解读**：北京 23.29%（第1）；重庆 17.00%（第3）；天津第27、河北第28，两省低于西部全部12省；31省均值12.01%、极差15.60、CV 26.18%。
- **可以怎么讲**：“东部的平均位置最高，但东部的最后两名就在这张图上。”
- **不能怎么讲**：不能说“北京数字经济全国第一”；不能把颜色深浅当综合水平；不能称该指标为数字经济规模。

### 图B　固定宽带接入配置（地图组合版）

- **文件**：`map_accounts_2024_combo.png` / `.pdf`
- **回答**：31省 D2 的空间格局；为何广东最低不等于设施最弱。
- **数据**：`map_panel_d2.csv`、`map_classes_d2.csv`；同书表16-36、表2-5（I203/A01），2024年末。
- **图形要素**：同图A；标注广东（39.51）与宁夏（53.14）。
- **核心解读**：海南58.14第1；宁夏53.14第5（西部最高）；广东39.51第31，但同年末千兆以上占比29.78%；东北集中在26—30位。
- **不能怎么讲**：不能说“广东/东北基础设施最差”；不能由账户密度推断普及率、资费与体验。

### 图C　四大区域：均值与中位数

- **文件**：`regional_mean_median_comparison.png` / `.pdf`
- **回答**：区域中心位置；两种口径是否给出相同排序。
- **数据**：`regional_mean_median.csv`。
- **图形要素**：双面板哑铃图（实心圆＝均值、空心菱形＝中位数）；右侧“均值→中位数”名次列（红色表示不一致）；底部提示带。
- **核心解读**：D1 均值“东＞西＞中＞东北”、中位数“东＞中＞西＞东北”；D2 两口径一致；东部 D1 极差14.75最大。
- **不能怎么讲**：不能说“西部比中部发达”；不能只报均值或中位数；不能把东北的“均衡”当优势。

### 图D　企业应用 × 接入配置（象限散点）

- **文件**：`scatter_ecommerce_accounts_quadrant.png` / `.pdf`
- **回答**：两个维度是否同步；哪些省最不同步。
- **数据**：`scatter_quadrant_panel.csv`、`scatter_quadrant_counts.csv`。
- **图形要素**：散点（区域分色）+ 均值虚线 + 右栏四组计数（9/7/7/8）。
- **核心解读**：Pearson 0.18、Spearman 0.27；平均名次差9.2位；北京(1/20)、广东(9/31)、宁夏(21/5)。
- **不能怎么讲**：不能说“两者无关”；不能把象限命名为“领先型/滞后型”；不能推因果。

### 图E　网上政府档级分布

- **文件**：`gov_category_distribution.png` / `.pdf`
- **回答**：档级在四大区域的分布是否呈直线梯度。
- **数据**：`gov_category_counts.csv`；2024年网上政府发展调查（S27），窗口2024年9月上旬—10月上旬。
- **图形要素**：四区域+全国的100%堆叠条（段内标“N省 百分比”）；右上档级图例。
- **核心解读**：优秀13/良好14/中等4；东部70.0%、西部41.7%、中部16.7%、东北0%。
- **不能怎么讲**：不能把档级换算成分数；不能排名；不能与 D1/D2 相加。

### 图F1　北京—河北对照卡

- **文件**：`case_card_beijing_hebei.png` / `.pdf`
- **回答**：区域内部差异如何与公共服务协作并存。
- **数据**：`stage5_key_numbers.json`（cases）；政策事实 C301（北京市政务服务局2024总结）、C302（河北省2025政府工作报告）。
- **图形要素**：左右双卡（省名、两项数据与名次、实施证据与来源、研究含义、不能推出）+ 中间差距带（14.75 / 0.10）。
- **核心解读**：配置差0.10、应用差14.75；北京417项一网通办、河北1053项跨省通办。
- **不能怎么讲**：不能说政策导致指标变化；不能把417与1053相加。
