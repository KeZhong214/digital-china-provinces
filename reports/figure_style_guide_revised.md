# 第五阶段图表视觉规范（修订版 V2）

> 风格关键词：**简洁、学术、低饱和、高级、适合汇报**。
> 实现入口：`scripts/stage5_style.py`（配色与画布）、`scripts/stage5_geo.py`（中国地图投影与底图）、`scripts/stage5_figures.py`（主图）、`scripts/stage5_cases.py`（案例卡）。第四阶段的字号、页眉、图注体系延续使用，避免阶段间风格断裂。

## 1. 主色与辅助色

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨黑 INK | `#1C1C1A` | 标题、省名、主数值 |
| 次级墨 INK_SOFT | `#41403C` | 副标题、数据标签、正文 |
| 中灰 MUTED | `#76736B` | 图注、坐标轴、次要说明 |

| 网格 GRID | `#E7E3DA` | 网格、分隔线 |

**规则**：一张图内强调色面积 ≤5%，只给结论级信息；不使用渐变、阴影、发光。

## 2. 地图用色规则

### 2.1 顺序色阶（两张地图共用）

| 级别 | 色值 | 说明 |
|---|---|---|
| 第5级（最高） | `#2E6373` | 深青 |
| 第4级 | `#5A8789` | |
| 第3级 | `#8DAFAC` | |
| 第2级 | `#B9CFCB` | |
| 第1级（最低） | `#DCE6E4` | 浅青灰 |

- **单色顺序色阶**，浅→深对应低→高；两张地图使用同一色阶，**同一颜色在两张图中含义相同**（只表示相对位置，不表示绝对值可比）。
- 非研究区（港澳台）：`#E9E7E1` 暖灰，不参与分级。
- 省界：白色 `0.55pt`；九段线：`#6E6A63`，`0.85pt`；南海诸岛小图底：`#FBFBFA`。
- **分级方法**：31省排序的**五等分中点断点**（避免断点与观测值重合），D1 断点 8.93/11.35/12.28/13.20，D2 断点 42.98/45.57/50.38/52.00；断点与各级省份清单见 `map_classes_d1.csv`、`map_classes_d2.csv`。
- **图注必须写明**：“分级为五分位断点，仅表示相对位置；灰色为港澳台，不在研究范围；底图仅作示意，不作测绘用途。”

### 2.2 标注规则

- 关键省份用“省名＋数值”两行标注（`#B24A32` 加粗，白色描边），其余省份只标省名（6.2–6.6pt，按底色自动切换白字/墨字）。
- 小面积省份（北京、天津、上海、宁夏、重庆、海南）用 0.5pt 引线外移标注，引线颜色与文字一致。
- 直辖市与特别行政区不另立图例；港澳台统一灰色并写入图注。

## 3. 四大区域对应色

| 区域 | 色值 | 明度定位 |
|---|---|---|
| 东部 | `#2E6373` 深青 | 最深，基准区域 |
| 中部 | `#A97845` 赭石 | 与深青形成冷暖对比 |
| 西部 | `#5F7F5C` 灰绿 | 冷色区，色相拉开 |
| 东北 | `#7C6A86` 灰紫 | 最浅，小样本（3省）区域 |

**规则**：四色饱和度均 <35%；区域色只用于**标识区域**，不表示数值高低；同图不出现第五种彩色。

## 5. 字号层级

| 层级 | 用途 | 字号（pt） | 字重 | 颜色 |
|---|---|---:|---|---|
| L0 眉标 | “图A ｜ 主图 · D1” | 8.5 | Bold | MUTED |
| L1 主标题 | 一句话结论 | 20–21 | Bold | INK |
| L2 副标题 | 期间、范围、单位、分级方式 | 11 | Regular | INK_SOFT |
| L3 面板标题 | 多面板子标题 | 9.6 | Bold | INK |
| L4 数据标签 | 数值、占比、名次 | 8.2–10.0 | Regular | INK_SOFT / MUTED |
| L4+ 地图省名 | 地图内省份 | 6.2–6.6 | Regular | 按底色 |
| L5 图注 | 来源、口径、边界 | 8.0 | Regular | MUTED |
| 特别 | 案例卡省名 | 26–28 | Bold | INK |
| 特别 | 案例卡主数值 | 27 | Bold | INK |

**正文（PPT 页面文字）建议**：标题 28–32pt、正文 16–18pt、页脚 10–11pt；与图表内文字形成两级层次，避免图表字号大于页面正文。

## 6. 数值标签规则

1. **图内数值保留 1–2 位小数**：D1 与 D2 地图标签 2 位（23.29、48.23），排名横条 1 位（23.3）。
2. **名次写作“第 X / 31”或“X/31”**；名次差不加正负号时须在注释说明方向。
3. **百分比与单位**：数值与单位之间空半格（“23.29%”“48.23 户/百人”）。
4. **不给推断性标签**：不使用“领先/滞后/达标/警戒”等评价词。
5. 底部表（CSV）保留 4 位小数，正文引用 2 位，**同一数字在不同载体上不得出现不同取整规则**。

## 7. 图注模板（五要素，缺一不可）

```
数据：<表名/来源编号>；统计期<年/月/窗口>。
指标定义：<公式或口径>；<不能读成什么>。
<分级/排序/参考线说明>；底表 <相对路径>。
```

**示例（图A）**：
> 数据：国家统计局《中国统计年鉴2025》表16-39（E02）；统计期2024年全年。
> 指标定义：有电子商务交易活动企业数 ÷ 同表调查企业数 × 100；调查范围为规模以上工业等一套表企业，不是全部企业或居民。
> 分级断点为31省排序的五等分中点；灰色为港澳台，不在研究范围；底图为阿里云 DataV 省级边界，仅作示意。

**禁止**：只写“数据来源：作者整理”；把图注写成结论段；在注中引入未在正文出现的数字。

## 9. PNG 尺寸、分辨率与长宽比

| 类型 | 画布（英寸） | 像素（300dpi） | 长宽比 | 适用 |
|---|---|---|---|---|
| 横版主图 | 13.333 × 7.5 | 3999 × 2250 | 16:9 | 图C、图D、图E、图F1—F3 |
| 地图竖版 | 10.6 × 8.4 | 3180 × 2520 | ≈1.26:1 | 图A、图B（纯地图版） |
| 地图横版 | 13.333 × 7.5 | 3999 × 2250 | 16:9 | 图A、图B（组合版，推荐） |

- 全部输出 **PNG（300dpi，白底不透明）+ PDF（矢量，嵌入 TrueType 子集）**。
- 不裁切、不透明边、不加外框；文件命名 `fig{字母}_{英文短名}.png/.pdf`。
- 打印稿建议 ≥300dpi；投影稿可用 200dpi 压缩版（另行导出，不覆盖原图）。

## 10. PPT 适配建议

1. **优先用「组合版」地图**（左图右表），信息密度与可读性最好；纯地图版留给打印或全屏展示。
2. **一页一图**：主图占页面 60% 以上；文字只保留中心句（≤20字）与页脚口径（10pt 灰字）。
3. **案例卡一卡一页**：图F1 可整页使用（左右对照），图F2/F3 单卡使用；不要在一页放三张卡（文字过小）。
4. **颜色适配**：投影仪偏色时，优先保证 5 级色阶的明度差；若现场对比度不足，可把第1级替换为 `#D2DFDD`（更深的浅色），不要改成高饱和色。
5. **动画**：只用“出现”与“淡入”，不做旋转、飞入；地图可分两步出现（先省界、后着色）。
6. **导出**：插入 PPT 时使用 PDF 或 300dpi PNG；缩放不超过 150%，避免锯齿。
7. **口径小字不可省**：每页底部保留一行 9–10pt 灰字（指标定义 + 来源），这是本研究区别于“网络榜单”的关键。
