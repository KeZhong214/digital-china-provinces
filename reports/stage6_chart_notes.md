## 主图1　`map_d1_ecommerce_final.png/.pdf`

| 项目 | 说明 |
|---|---|
| 用途 | P4 主图：D1 的全国空间格局 |
| 口径 | 企业电商参与比例＝有电商交易企业数÷同表调查企业数×100；2024年全年；31省 |
| 分级 | 五等分中点断点 8.93 / 11.35 / 12.28 / 13.20（各级 6/6/6/6/7 省） |
| 地图 | 阿里云 DataV 省级边界；Albers 等积圆锥（25°N/47°N，中央经线105°E）；含台湾省（完整可见、双行标注）、港澳灰色；南海诸岛小图置于地图**西南角**，不遮挡台湾 |
| 标签 | 31省编号 01—31（按区域分组），右侧对照表（编号/省份/区域/数值/档级） |
| 高亮 | 北京、河北（编号陶红、表行加粗） |
| 推荐讲法 | ①先教读图："数字是编号，右侧表查省名与数值"；②指北京第1、重庆第3、河北第28；③补中段"第10—22位只差1.64个百分点" |
| 不能怎么讲 | 不能说"北京数字经济全国第一"；不能把颜色深浅当综合水平；不能称其为数字经济规模 |
| 现场风险 | 后排可能看不清编号 → 用激光笔配合右侧表讲，不改字号 |

## 主图2　`map_d2_accounts_final.png/.pdf`

| 项目 | 说明 |
|---|---|
| 用途 | P5 主图：D2 的全国空间格局，并内置"广东最低≠设施最弱"的边界 |
| 口径 | 固定宽带账户（万户）÷年末常住人口（万人）×100；2024年末 |
| 分级 | 断点 42.98 / 45.57 / 50.38 / 52.00（6/6/6/6/7 省） |
| 高亮 | 广东、宁夏 |
| 推荐讲法 | ①分布比 D1 集中（CV 10.66%）；②西部有高位：宁夏第5、青海第7、新疆第10；③广东最低但千兆占比29.78% |
| 不能怎么讲 | 不能说"广东/东北基础设施最差"；不能由账户密度推断普及率、资费或体验 |
| 图注必须 | "反映接入配置强度，不等于完整网络质量或居民实际普及率" |

## 主图3　`regional_mean_median_final.png/.pdf`

| 项目 | 说明 |
|---|---|
| 用途 | P6 主图：区域中心位置与口径敏感性 |
| 数据 | `regional_mean_median.csv`（省内等权平均） |
| 制作 | 双面板哑铃图；右侧"均值→中位数"名次列，红色标出不一致（中部3→2、西部2→3） |
| 推荐讲法 | ①东部均值最高、极差最大；②东北最均衡但均值最低；③中西部均值/中位数次序相反，删重庆后反转 |
| 不能怎么讲 | 不能说"西部比中部发达/落后"；不能只报一个口径；不能把哑铃线当置信区间 |
| 现场风险 | 两个面板单位不同，讲解时要分别指认，不能横向比较 |

## 主图4　`scatter_d1_d2_final.png/.pdf`

| 项目 | 说明 |
|---|---|
| 用途 | P7 主图：两个维度不同步 |
| 数据 | 31省 D1×D2；均值线 x=48.23、y=12.01；四组计数 9/7/7/8 |
| 推荐讲法 | ①先问"如果两个指标测同一件事，点会怎么排"；②指北京、广东、宁夏三组；③京冀两点几乎垂直对齐 |
| 不能怎么讲 | 不能说"两者无关"或"基础设施没用"；不能把象限命名为"领先型/滞后型"；不能推因果 |
| 注意 | 低相关只说明"省级横截面不能互相预测"，不代表个体层面无关系 |

## 主图5　`gov_category_matrix_final.png/.pdf`

| 项目 | 说明 |
|---|---|
| 用途 | P8 主图：D3 档级的区域分布 |
| 数据 | `gov_matrix_layout.csv`；2024年9月上旬—10月上旬调查 |
| 形式 | 四大区域各一行、31格（0.52×0.52 in），颜色表示档级；右侧档级计数 + 各区域优秀率横条 |
| 推荐讲法 | ①每格一省；②优秀13/良好14/中等4；③西部41.7%高于中部16.7%，东北0% |
| 不能怎么讲 | 不能换算成分数、不能排名、不能与其他指标相加；东北仅3省，比例易被放大 |
| 图注必须 | "本图为档级分布展示，不构成连续分数排序" |

## 主图7A　`case_card_beijing_hebei_final.png/.pdf`

| 项目 | 说明 |
|---|---|
| 用途 | P10 主图：区域内部差异 + 公共服务协同 |
| 数据 | 北京23.29/45.45、河北8.53/45.35；差距带14.75与0.10 |

| 推荐讲法 | ①先看两项数据的对比；②再看两省实践；③落到"抓手是标准互认，不是拉平指标" |

| 现场风险 | 中间差距带字号最大，容易抢焦点 → 讲解时先指左右两卡，再指中间 |

## 通用制作核对

1. 全部主图由 `scripts/stage6_figures.py`、`scripts/stage6_cases.py` 生成；配色字号集中在 `stage5_style.py`；地图投影与底图在 `stage5_geo.py`。
2. 底图 sha256 记录在 `data/processed/stage5/basemap_manifest.json`；重跑前需确保 `data/raw/geo/china_provinces_100000_full.json` 存在。
3. 分级断点、各级省份清单在 `map_classes_d1.csv`、`map_classes_d2.csv`；改分级须同步改图注。
4. 编号规则在 `data/processed/stage6/province_numbering.csv`；改编号须同步改右侧对照表与图注。
5. 图中所有省名与数值由底表驱动，**不得手改图片**。
6. 主图为 16:9（3999×2250）；纯地图版为 10.6×8.4（3180×2520）。
