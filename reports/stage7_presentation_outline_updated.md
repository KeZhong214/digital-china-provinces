## 三、逐页文案

### P1　数字中国的省际图景：三个维度，一张画像

- **中心句**：用31省公开数据，做一张能看懂结构、也说得清局限的画像。
- **上屏**：主标题 + 副标题（"31省 · 2024 · 三维画像与探索性综合评价"）+ 汇报人/课程/日期。
- **口播**：一句话说明研究问题：差异在哪、能否综合、对区域协调意味着什么。

### P2　为什么从省际差异看中国式现代化

- **中心句**：全国平均会掩盖"谁被平均掉了"。
- **上屏**（三行）：数字化既是动能也是差距放大器｜省是政策与数据的最小单元｜区域协调关心差距落在哪。
- **口播**：数字鸿沟的双面性；本研究只做描述与评价，不做政策效果评估。

### P3　三项数据、一套可复算的方法

- **中心句**：三项指标各自标准化，等权合成，45个场景检验稳健性。
- **上屏**（小表）：

| 维度 | 数据 | 期间 |
|---|---|---|
| D1 企业数字交易应用 | 电商参与比例 | 2024全年 |
| D2 固定宽带接入配置 | 每百人账户数 | 2024年末 |
| D3 数字政府发展指数 | 清华团队指数 | 载2025报告，窗口未明确 |

- **口播**：Min–Max 到0—100、等权、同分规则；强调这是**本研究探索性评价**，不是官方排名；D3 的来源与窗口用一句话交代即可。
- **只写**：表格 + "探索性评价，非官方排名"。

### P4　先看结构：四大区域与31省

- **中心句**：先用一张图建立"区域—省份"的结构感。
- **上屏**：旭日图 + "内环区域、外环31省、颜色＝D1五分位"。
- **口播**：东部10、中部6、西部12、东北3；角度不表示数值，比较看后面的地图与画像。
- **只写**：中心句 + 图 + "结构示意，不作精确比较"。

### P5　企业数字交易应用：北京最高，东部并非整体高位

- **中心句**：前五有重庆，后五有天津、河北。
- **上屏**：主图1 + "北京23.29%，天津第27、河北第28"。
- **口播**：地图编号对应右侧双栏表；第10—22位只差1.64个百分点，名次被放大。
- **只写**：中心句 + 图 + 页脚口径。

### P6　固定宽带配置：海南最高，广东最低

- **中心句**：广东最后一名，但这张图测的是配置，不是设施强弱。
- **上屏**：主图2 + "广东39.51（第31），千兆占比29.78%"。
- **口播**：西部有宁夏第5、青海第7、新疆第10；账户密度受家庭规模、机构账户与固定/移动替代影响。
- **只写**：中心句 + 图 + "只测接入配置，不测网速与覆盖"。

### P7　网上政府档级：不是一条从东到西的直线

- **中心句**：西部优秀率41.7%，高于中部16.7%；东北0%。
- **上屏**：档级矩阵（stage6 `gov_category_matrix_final`）。
- **口播**：优秀13/良好14/中等4；**强调这是2024年调查档级，与综合分用的 D3 连续指数不是同一变量**。
- **只写**：中心句 + 图 + "档级分类，不转分数；与 D3 指数不同源"。

### P8　三个维度，一张综合画像

- **中心句**：同一行三个色块，就能看出一个省"强在哪、弱在哪"。
- **上屏**：主图3（画像热力矩阵）+ 一句"浙江77.7、北京75.6、上海68.2"。
- **口播**：教读图（名次｜省名｜D1/D2/D3｜综合分条）；点出前五结构各不相同：浙江靠设施与治理、北京靠应用与治理、海南靠配置、江苏靠设施。
- **只写**：中心句 + 图 + "深色＝在该指标中相对更高"。

### P9　探索性综合排名：前五稳定，中段看区间

- **中心句**：前五可以点名，第11名之后只能讲区间。
- **上屏**：主图4（排名图）或主图5（综合地图）+ 前五得分。
- **口播**：
  - 前五：浙江77.71、北京75.60、上海68.22、海南65.07、江苏63.66；
  - 第6—10：重庆、福建、山东、安徽、四川（讲梯队）；
  - 广东第18但区间6—27，宁夏第20但9—28——**名次取决于权重与 D2 定义**。
- **只写**：前五 + "第11名后看区间"。

### P10　换个权重，谁会动？

- **中心句**：45个场景里，前五基本不动，广东、宁夏、青海、新疆动得最多。
- **上屏**：一张小的"名次区间"表（4—6省）。
- **口播**：Spearman 0.86—1.00；最大变动12位；"前五点名、中段讲区间"就是从这里来的。
- **只写**：区间表 + "稳健性决定表达方式"。

### P11　区域差异：东部最高，内部差距也最大

- **中心句**：东部均值56.7，但极差49.7；西部两极分化。
- **上屏**：区域统计表（均值/中位数/极差/CV）。
- **口播**：东部长三角与京津冀两端；中部集中9—25名；西部重庆第6、西藏第30；东北三省28—31。
- **只写**：表格 + "区域均值≠区域内部"。

### P12　两个维度不同步：广东、宁夏、重庆

- **中心句**：综合分接近，结构可以完全相反。
- **上屏**：散点图（stage6 `scatter_d1_d2_final`）+ 一对反例。
- **口播**：广东（D3强、D2为0）与宁夏（D2强、D3弱）只差1.65分；重庆三维最均衡。
- **只写**：中心句 + 图。

### P13　京冀与宁夏：差异如何落到协调

- **中心句**：差在应用与治理，不在配置；宁夏走的是设施路径。
- **上屏**：京冀对照卡（主图7A）。
- **口播**：北京/河北 D2 几乎相同（31.9/31.3），差距在 D1 与 D3；京津冀417项一网通办、河北1053项跨省通办；宁夏中卫算力与算电协同。
- **只写**：中心句 + 图 + "实施事实≠因果效果"。

### P14　结论：结构比名次更重要

- **中心句**：综合分告诉我们"谁在什么组合下靠前"，而不是"谁更现代化"。
- **上屏**（三条）：
  1. 差异显著，但三项格局不同
  2. 综合可分层，结构比名次更有信息量
  3. 稳健性决定表达：前五点名、中段讲区间
- **口播**：局限三句（代理指标、等权是设定、D3窗口未明确）；落回区域协调：功能互补与接口衔接。
- **只写**：三条结论 + 一行局限。
