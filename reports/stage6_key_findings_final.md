# 第六阶段关键发现清单（终版）

> 三类严格区分：**可以明确说**（可直接上 PPT）、**需要谨慎说**（必须带限定）、**不能说**（越界，须当场纠正）。
> 数字来源：`data/processed/stage6/stage6_key_numbers.json`、`data/processed/stage5/`；口径见 `stage6_research_draft_final.md` 附录A。
> 固定口径：D1 中西部＝“接近、排序不稳健”；东北＝“三项相对靠后，但仅3省，不外推”；研究定位＝“分项画像”。

## 一、可以明确说

1. **31省在企业数字交易应用和固定宽带接入配置上存在明显差异。**
   - D1：均值12.01%、中位数11.96%、极差15.60个百分点、CV 26.18%。
   - D2：均值48.23、中位数48.74、极差18.63、CV 10.66%。

2. **区域差异同时存在于区域之间和区域内部。**
   - 东部 D1 均值13.83（四区域最高），内部极差14.75（同样最高），且恰为北京与河北之差。
   - 东北 D1 极差0.69、CV 3.84%（四区域最小），但均值8.13（最低）——低位均衡。

3. **不同维度之间并不同步。**
   - D1 与 D2 的 Pearson 0.18、Spearman 0.27（n=31，描述性）；平均绝对名次差9.2位，15省≥10位、8省≥15位。
   - 北京 D1 第1/D2 第20；广东 9/31；宁夏 21/5。

4. **D1 最高北京23.29%（第1）、最低吉林7.69%（第31）；前五为北京、山东、重庆、海南、上海；后五为天津、河北、黑龙江、辽宁、吉林。**
   - 后五中有两个东部省份（天津第27、河北第28），且两省低于西部全部12省。

5. **D2 最高海南58.14（第1）、最低广东39.51（第31）；前五为海南、江苏、浙江、福建、宁夏；后五为广东、吉林、云南、内蒙古、黑龙江。**
   - 宁夏是西部最高（第5）；东北三省集中在第26—30位。

6. **2024年网上政府档级：优秀13省（41.9%）、良好14省（45.2%）、中等4省（12.9%）。**
   - 区域优秀率：东部70.0%、西部41.7%、中部16.7%、东北0%；中等4省为辽宁、黑龙江、西藏、新疆。

7. **京冀对照：北京 D1 23.29（第1）、D2 45.45（第20）；河北 D1 8.53（第28）、D2 45.35（第21）。**
   - 应用差14.75个百分点，接入配置差0.10户/百人。

8. **广东 D2 为31省最低（39.51），但同年末千兆以上用户占固定宽带29.78%（1503.5/5049.5万户，单省同段）。**

9. **中卫市2024年7个算力项目建成投运、标准机架累计12.1万架；国家发展改革委答复确认2024年国家数据局在宁夏等枢纽部署算电协同先行先试。**

## 二、需要谨慎说

| 说法 | 必须带的限定 |
|---|---|
| **东部整体水平较高，但内部差异也显著** | 只能说“在两个代理指标的均值上最高”；必须同时给出东部内部极差（D1 14.75）与 CV（29.26%） |
| **中西部在 D1 上处于接近区间，排序依赖统计口径** | 必须同时给均值（西部11.80＞中部11.36）与中位数（中部12.23＞西部11.40），并说明删重庆后西部11.32 |
| **东北整体相对靠后，但样本仅3省** | 必须标注 n=3，说明只在本研究三项指标内成立，不外推为“全面落后” |
| 宁夏体现不同发展路径 | 应说“在本研究两个代理上呈‘配置高、应用中’的组合，并有算力项目与算电协同部署佐证”，不判定路径更优 |
| 固定宽带账户配置反映部分接入基础 | 必须补“但不测速率、覆盖、资费与体验，不等于完整基础设施质量” |
| 两个维度弱相关 | 应说“省级横截面上不能互相预测（r=0.18/0.27）”，不说“无关” |
| 案例说明协作在发生 | 只说“实施事实存在”，不说“产生效果” |

## 三、不能说

1. **不能把本研究说成官方或权威的31省数字现代化综合排名。** —— 本研究未合成任何总分。
2. **不能把案例材料当作因果证据。** —— 无对照、无前后数据；事项数不等于办理量或企业受益。
3. **不能把单一指标等同于整体数字化水平。** —— D1 只测参与面、D2 只测配置、D3 只有档级。
4. 不能说“某省数字现代化水平全国第一/最差”。
5. 不能说“东部比西部发达/落后X年”（无时间序列）。
6. 不能说“广东/东北基础设施全国最差”（账户密度不测速率、覆盖与体验）。
7. 不能说“某省数字政府得分排名第X”（只有档级，没有分数）。
8. 不能说“区域差距正在缩小/扩大”（只有一个年度截面）。
9. 不能说“数字鸿沟已经/尚未缩小”（未测量居民使用、技能、资费与体验）。
10. 不能说“本研究证明国家政策有效”（不做政策评估）。

## 四、一句话版本

> 用2024年的两项官方代理与一项政府档级看，31省的数字图景不是一个可以排成一列的梯度：北京应用最高但配置只居中，广东配置最低却有近三成千兆用户，宁夏配置第5而应用第21；东部均值最高、内部差距也最大；中西部在应用指标上接近、排序依赖口径。因此我们不做综合总榜，而主张区域协调的重点在于公共服务与基础设施的“接口”是否接得上。
