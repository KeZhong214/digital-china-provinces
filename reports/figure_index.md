## 图1　调查企业交易型数字应用的省际排序

- **文件**：`fig1_ecommerce_ranking.png` / `.pdf`（竖版 8.7×11.0 in）
- **回答的问题**：2024年，31省企业电商参与比例的分布是什么样？高值、低值与"中间大多数"分别由谁构成？东部内部是否也有低位省份？
- **数据**：31省 `d1_ecommerce_pct`（2024年全年，%）；来源《中国统计年鉴2025》表16-39（E02）。
- **底表**：`data/processed/stage4/fig1_d1_ranking.csv`
- **图形要素**：横向条形（按数值降序）+ 名次列 + 区域分色 + 全国合计参考线（12.77%，企业数加权）+ 提示带（京冀差14.75个百分点）。
- **核心解读**：
  1. 均值为12.01%、中位数为11.96%，极差15.60个百分点，CV 26.18%——分布右偏，北京一枝独秀。
  2. 头部并非清一色东部：重庆第3（17.00%）、山东第2（17.04%），两者几乎并列。
  3. 尾部有天津（第27）、河北（第28）两个东部省份，且低于西部全部12省。
  4. 第10位到第22位只差1.64个百分点却容纳13个省——名次被放大。
- **可以怎么讲**："东部的平均位置最高，但东部的最后两名就在这张图的底部。"
- **不能怎么讲**：
  - 不能说"北京数字经济发展水平全国第一"——本指标只测调查企业的电商参与面，不测规模、产出或效率。
  - 不能说"河北数字化落后"——D2 上河北与北京几乎持平，档级为良好。
  - 不能把名次当成差距大小（中段省份差距不足1个百分点）。

## 图2　固定宽带接入配置的省际排序

- **文件**：`fig2_broadband_ranking.png` / `.pdf`（竖版 8.7×11.0 in）
- **回答的问题**：31省固定宽带账户配置的分布形态如何？为什么最低的广东不能被读成"设施最弱"？西部有哪些高位省份？
- **数据**：31省 `d2_accounts_per100`（2024年末，户/百人）；来源同书表16-36、表2-5（I203、A01）。
- **底表**：`data/processed/stage4/fig2_d2_ranking.csv`
- **图形要素**：横向条形 + 名次列 + 区域分色 + 31省等权均值参考线（48.23）+ 提示带（广东39.51 + 千兆29.78%）。
- **核心解读**：
  1. 均值48.23、中位数48.74，极差18.63，CV 10.66%——比 D1 集中，但区域分层更明显。
  2. 前五为海南、江苏、浙江、福建、宁夏；宁夏是西部最高（第5）。
  3. 广东全国最低（39.51），但同年末千兆以上用户占固定宽带29.78%（1503.5/5049.5万户）。
  4. 东北三省集中在后段（辽宁26、黑龙江27、吉林30）。
- **可以怎么讲**："这张图测的是账户配置，不是网速，也不是覆盖质量——所以广东的最后一名不等于广东的设施最弱。"
- **不能怎么讲**：
  - 不能说"广东基础设施全国最差"或"东北基础设施最差"。
  - 不能用账户密度推断居民普及率、资费水平或使用体验。
  - 不能把 29.78% 外推为31省质量排名（只有单省同段数据）。

## 图3　四大区域：均值与中位数给出的答案不完全相同

- **文件**：`fig3_regional_center_comparison.png` / `.pdf`（横版 13.333×7.5 in）
- **回答的问题**：四大区域的中心位置在哪？均值与中位数是否给出相同排序？区域内部差异有多大？
- **数据**：`fig3_regional_center_dispersion.csv`（由31省面板按区域等权计算）。
- **图形要素**：双面板点—区间图；圆点＝均值、空心菱形＝中位数、横线＝省内最小—最大极差；中部/西部两行加浅底；面板顶部标注排序结论与极差序列。
- **核心解读**：
  1. D1：均值排序"东＞西＞中＞东北"，中位数排序"东＞中＞西＞东北"——**中西部次序对调**。
  2. D2：两种中心统计量排序一致，但西部与中部差距很小（均值差0.22、中位数差3.01）。
  3. 区域内部极差：D1 东部14.75＞西部8.10＞中部4.30＞东北0.69；D2 东部18.63＞西部12.23＞中部7.20＞东北3.27。
  4. 东北"最均衡"是低位均衡（D1均值8.13，CV 3.84%）。
- **可以怎么讲**："同一个西部，均值比中部高、中位数比中部低——不是数据错了，是'中心'本身就取决于你用哪个统计量。"
- **不能怎么讲**：
  - 不能说"西部比中部发达/落后"——只能说在该指标、该口径下的位置。
  - 不能把横线当置信区间或显著性区间（它是极差）。
  - 不能用区域均值代替区域内部（东部极差=京冀差14.75）。

## 图4　两个维度不能相互替代：企业应用 × 接入配置

- **文件**：`fig4_application_vs_access_scatter.png` / `.pdf`（横版 13.333×7.5 in）
- **回答的问题**：D1 与 D2 之间是什么关系？哪些省份名次差最大？为什么不能合成一个总分？
- **数据**：31省 `d1_ecommerce_pct` × `d2_accounts_per100`；`stage4_correlations.csv`、`stage4_rank_gap_table.csv`。
- **图形要素**：散点（区域分色、关键省份标注）+ 31省中位数虚线参考 + 右侧"名次差最大的四省"栏（D1名次→D2名次/差值/方向）。
- **核心解读**：
  1. Pearson 0.18、Spearman 0.27（n=31，描述性）——两个代理几乎不重合。
  2. 平均绝对名次差9.2位，15省≥10位，8省≥15位。
  3. 三种形态：应用领先（广东9/31、北京1/20、山东2/17）、配置领先（宁夏21/5、天津27/9、江苏17/2）、大体同步（上海5/6、海南4/1、浙江6/3）。
  4. 北京与河北在图中几乎垂直对齐（配置相近、应用相差14.75个百分点）。
- **可以怎么讲**："如果两个指标测的是同一件事，这些点应该沿着一条斜线排开；它们没有。"
- **不能怎么讲**：
  - 不能说"两者无关"或"基础设施对数字经济没用"——低相关只说明省级横截面上不能互相预测。
  - 不能把中位数虚线当象限分类或优劣分界。
  - 不能据散点位置推断任何省的"综合水平"。

## 图5　2024年网上政府发展档级的区域分布

- **文件**：`fig5_government_tier_distribution.png` / `.pdf`（横版 13.333×7.5 in）
- **回答的问题**：优秀/良好/中等三档在四大区域如何分布？是否呈现"东—中—西"的直线梯度？哪些省是中等档？
- **数据**：`fig5_government_tier_by_region.csv`、`fig5_government_tier_by_province.csv`；来源2024年网上政府发展调查（S27），窗口2024年9月上旬—10月上旬。
- **图形要素**：上部100%堆叠条（四大区域+全国，段内标"个数（占比）"）；下部31省条带（按区域分块、按档级着色、省名竖排）。
- **核心解读**：
  1. 31省：优秀13（41.9%）、良好14（45.2%）、中等4（12.9%）。
  2. 东部优秀率70%、中部16.7%、西部41.7%、东北0%。
  3. 中等档4省：辽宁、黑龙江、西藏、新疆——**东北三省中2省为中等，西藏为西部唯一中等**。
  4. 西部5省优秀（内蒙古、重庆、四川、贵州、云南），高于中部的1个。
- **可以怎么讲**："如果档级是一条从东到西的直线，西部不该有5个优秀、中部不该只有1个。"
- **不能怎么讲**：
  - 不能把"优秀"换算成分数、不能排名、不能推断档内次序。
  - 不能说"某省数字政府比另一省强"——只能说落在同档或不同档。
  - 不能把档级与 D1/D2 相加或相互校验为"综合表现"。

## 图6　三个案例：数据事实、实施证据与解释边界

- **文件**：`fig6_case_evidence_cards.png` / `.pdf`（横版 13.333×7.5 in）
- **回答的问题**：京、冀、宁三地的数据位置与政策实践如何对应？各自能推出什么、不能推出什么？
- **数据**：`fig6_case_card_table.csv`；政策事实来自 C301（北京市政务服务和数据管理局2024年工作总结）、C302（河北省2025年政府工作报告）、C305（中卫市数据局2024年工作总结）、C306（国家发展改革委答复）。
- **图形要素**：三张同构卡片（省名+区域/档级 → 两项数据+31格名次轨道 → 实施事实+来源 → 研究启示 → 不能推出）。
- **核心解读**：
  1. 北京：D1 第1、D2 第20，档级优秀；京津冀"一网通办"417项、三地自贸区230项同事同标。
  2. 河北：D1 第28、D2 第21，档级良好；京津冀1053项跨省通办；与北京配置仅差0.10户/百人。
  3. 宁夏：D1 第21、D2 第5，档级良好；中卫7个算力项目投运、标准机架12.1万架；2024年国家数据局在宁夏等枢纽部署算电协同。
- **可以怎么讲**："差异不等于落后：京冀差在应用不在配置，宁夏强在配置与算力不在交易应用。"
- **不能怎么讲**：
  - 不能说政策导致指标变化（无前后对比、无对照）。
  - 不能把417与1053相加或比较多少（口径不同）。
  - 不能把中卫数据当全宁夏，不能把机架数当利用率。
  - 不能说这些实践缩小了区域差距或提升了获得感（未测量）。

## 图6B　广东：一个账户密度，不能代表基础设施强弱（备用）

- **文件**：`fig6b_guangdong_method_warning.png` / `.pdf`（横版 13.333×7.5 in）
- **回答的问题**：为什么不能据 D2 第31判断广东设施落后？这个案例对方法有什么启示？
- **数据**：广东 D1 12.77%（第9）、D2 39.51（第31）、档级优秀；固定宽带5049.5万户、千兆以上1503.5万户、占比29.78%（C303，2024年12月运行情况，2025-01-26）。
- **图形要素**：单张案例卡（同图6设计）+ 右侧"为什么不能这样读"三条解释 + 提示带（方法意义）。
- **核心解读**：
  1. 账户密度＝全部账户÷常住人口，分子含家庭与机构账户，不是去重居民数，也不测速率与覆盖。
  2. 家庭户规模、机构账户、固定/移动替代、人口流动都可能影响该比值；本项目无同年31省拆分数据，不能确定原因。
  3. 千兆占比29.78%说明"配置"与"质量结构"是两个测量；但只有单省数据，不能排31省质量名次。
- **可以怎么讲**："这不是替广东辩护，而是说明指标的名字写错了，描述就会变成判断。"
- **不能怎么讲**：
  - 不能反过来说"广东设施最强"。
  - 不能把单省千兆占比当作31省质量水平。
  - 不能据此修改任何省份的 D1/D2 数值。
