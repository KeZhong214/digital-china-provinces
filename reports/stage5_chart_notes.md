## 图A　`map_ecommerce_2024_combo.png` / `map_ecommerce_2024.png`

| 项目 | 说明 |
|---|---|
| 目的 | 用地图呈现 D1 的空间格局，作为 P4 的主图 |
| 口径 | 企业电商参与比例＝有电商交易企业数÷同表调查企业数×100；2024年全年；31省 |
| 分级 | 31省排序五等分中点断点：**8.93 / 11.35 / 12.28 / 13.20**；各级省份数 6/6/6/6/7 |
| 底图 | 阿里云 DataV 省级边界 GeoJSON（`data/raw/geo/china_provinces_100000_full.json`，sha256 见 `basemap_manifest.json`）；Albers 等积圆锥投影（25°N/47°N，中央经线105°E） |

| 注意事项 | ①颜色只表示相对位置，不表示绝对差距；②地图分级与排序图的数值标签不完全等价；③灰色区域不属于研究范围；④底图仅作示意，不作测绘用途 |
| 推荐场景 | P4 主图；答辩 B2 可切纯地图版 |

## 图C　`regional_mean_median_comparison.png`

| 项目 | 说明 |
|---|---|
| 目的 | 一张图同时给出均值、中位数与两种口径下的区域名次，支撑“排序依赖口径” |
| 口径 | 区域内31省等权平均，不按人口或企业数加权；东北 n=3 |
| 制作要点 | 哑铃线连接均值与中位数；右侧“均值→中位数”名次列，红色标出不一致（中部3→2、西部2→3） |
| 注意事项 | ①圆点与菱形不是置信区间；②D1 与 D2 的纵轴单位不同，不可横向比较；③名次变化只说明口径敏感，不说明“哪个更真实” |
| 推荐场景 | P6 主图；若时间紧，可只讲左panel（D1） |

## 通用制作核对

1. 所有图由 `scripts/stage5_figures.py`、`scripts/stage5_cases.py` 生成，可重跑；配色与字号集中在 `stage5_style.py`。
2. 底图来源与 sha256 记录在 `data/processed/stage5/basemap_manifest.json`；底图不随报告分发时，重跑需先恢复该文件。
3. 分级断点、各级省份清单在 `map_classes_d1.csv`、`map_classes_d2.csv`，改分级后须同步更新图注。
4. 图中所有省名与数值均由 `stage5_key_numbers.json`/底表驱动，**不得手改图片**。
5. PDF 为矢量版，插入 Word/PPT 缩放不失真；PNG 为 300dpi，用于截图与打印。
