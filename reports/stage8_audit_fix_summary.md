## P0-1　敏感性三类含义：45个ID ≠ 45个独立设定

**核对结果**：审核报告完全成立。原45个场景中，3个"单维50%"方案 (0.5,0.25,0.25)、(0.25,0.5,0.25)、(0.25,0.25,0.5) **恰好落在36格权重网格内**，属于重复计数。

**旧表述**：45个场景（权重三方案＋36格权重网格＋两种标准化＋三类剔除维度）。

**新表述**：**42个唯一参数场景**＝基准1＋权重网格36＋标准化替代2＋剔除维度3；3个"单维50%"方案单列为讲解用，不重复计入频次。

**数据依据**：`sensitivity_scenarios_deduplicated.csv`（42行场景清单，含权重三元组、标准化方式、剔除维度、与基准的Spearman、最大名次变动、top5成员）；`sensitivity_by_type.csv`（31省×类别区间）。

## P0-2　广东"提高权重就进前十"是错误论断

**旧表述**："只要提高 D1 或 D3 的权重、或剔除 D2，广东就进入前10。"

**新表述**：
> 广东基准排名第18，对宽带账户配置代理的权重及维度保留与否高度敏感。适度改变权重会引发明显名次变化（D1 权重50%→第16、D3 权重50%→第11、D2 权重50%→第24）；若完全剔除 D2，其名次变为第6。这反映的是模型对指标选择的依赖，不能解读为广东真实现代化水平在不同情景中发生变化。

**数据依据**（`stage8_key_numbers.json` → `special_weight_schemes` / `guangdong_drop`）：

| 设定 | 广东名次 |
|---|---:|
| 基准等权 | 18 |
| D1 = 50% | **16**（不是前10） |
| D2 = 50% | 24 |
| D3 = 50% | **11**（不是前10） |
| 剔除 D1 | 23 |
| 剔除 D2 | **6** |
| 剔除 D3 | 27 |

**旧表述**："基准前五在45个场景中全部保持前10……北京、上海、海南的 top5 出现率均 ≥97%"（易被读成"前五各自的名次稳定"）。

**数据依据**：`sensitivity_by_type.csv` 的 `all_min/all_max/all_top5_freq`。

## P0-4　"西部CV最高"与数据矛盾

**核对结果**：审核报告成立。综合分 CV 排序为 **东北45.95% ＞ 西部33.36% ＞ 东部28.07% ＞ 中部24.18%**；极差排序为 **东部49.68 ＞ 西部42.97 ＞ 中部30.41 ＞ 东北14.33**。

**旧表述**："西部 CV 33.36% 为四区域最高""西部最不均衡"。

**新表述**：
> 东部综合分极差最大（49.68，河北28.03—浙江77.71）；西部 CV 高于东部和中部（33.36% vs 28.07%、24.18%），体现明显内部差异；东北 CV 更高（45.95%），但样本仅3省，解释须谨慎。

**数据依据**：`data/processed/stage7/regional_composite_stats.csv`（数值未变，表述更正）。
